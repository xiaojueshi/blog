# 实施与验收记录

## 2026-10-24：首个本地可运行版本

已实现响应式公开博客、单管理员工作台、本地 SQLite、Markdown 编辑与渲染、自动保存、独立发布快照、撤回、图片权限、版本历史和备份导入导出。

### 自动化验证

- Node 原生测试：12 项通过，覆盖可见性、公开快照、中文搜索、SQLite 读写、历史、冲突回滚和密码摘要。
- Vitest：2 个文件、6 项通过，覆盖 Markdown 安全过滤、GFM、公式、代码、Mermaid 源码及存储逻辑。
- 浏览器：5 项通过，使用独立测试数据库，不操作个人工作台数据。
- Vue 应用、服务端、共享模块及构建配置类型检查通过。
- Nuxt 生产构建通过；备份恢复测试实际启动了 Node.js 生产产物。

浏览器验证包括登录、写作、自动保存、刷新恢复、手机预览、发布、发布中继续输入、未发布修改隔离、修订冲突、撤回与备份。图片验证包括私密、公开、未发布新附件和撤回后的访问规则。

备份实际恢复到独立的生产服务数据库，并检查公开快照、私人编辑稿与原始图片；另检查同库恢复不覆盖已有内容。

公开阅读验证包括禁用 JavaScript 的 SSR、减少动态效果、中文搜索、空结果恢复及移动导航。

### 视觉验收

使用实际浏览器打开网页，检查首页和阅读页；自动生成 1440、768、390、320px 下的整页截图，覆盖首页、文章列表、三类 Markdown 阅读样例、知识库、项目、关于和登录页，共 36 个页面与尺寸组合。

后台额外保存桌面列表、手机列表、桌面分栏编辑器和手机预览截图。页面没有检测到横向溢出；公开页面测试没有捕获到 JavaScript 异常。

截图复核后提高了次要正文的字号和对比度，增加手机工作台的全部、已发布、私密筛选及数据管理入口，并将长标题改为可换行输入。几何品牌元素在手机上简化，减少动态效果时保留完整内容。

代表截图保存在 `docs/screenshots`。完整截图、失败追踪与报告由 Playwright 输出到 `test-results` 和 `playwright-report`，CI 上传这些验收产物。

### 本轮修复

- Nuxt 共享模块路径导致生产构建失败。
- 后台请求类型推断过深。
- 开发依赖预构建引起的页面重载，以及测试早于 hydration 操作的问题。
- Nuxt 本机 IPC 代理下首次管理员初始化误判请求来源；仅开发环境兼容该代理，生产环境不信任客户端转发头。
- 工作台 SSR 刷新未转发会话而返回 401。
- 发布响应可能覆盖请求期间新输入的问题。
- 管理页面增加禁止缓存的响应头。

## 视觉第二版：用户反馈修订

用户明确不喜欢独立 x 标识、旧主标语、文艺化表达及偏暖灰绿的色调。现已改用纯文字 XIAOJUESHI 字标，主标语替换为“永远相信美好的事情即将发生”，统一白、黑、中性灰和无衬线排版。桌面装饰改为无字母线框立方体，手机端隐藏装饰；文章、知识库、项目、关于和工作台文案同步简化。此反馈覆盖首版暖白与低饱和强调色的设计约定。


## 工作台升级：知识库、内容组织、设置与主题

后台拆分为内容、独立编辑器、知识库、内容组织、附件和设置。设置包含基本信息、外观、编辑与发布、数据管理四个 Tab，数据导出不再混入写作界面。

内置类型支持改名、排序、停用和默认值；分类与标签使用稳定 ID，支持分类迁移、标签合并及批量设置。知识库支持嵌套章节、调整父章节与顺序、收录现有内容、章节内创建笔记、移除引用后撤销、归档与恢复。公开阅读提供目录、面包屑和前后篇，仅使用发布快照，过滤私密内容和空章节。

浅色、深色、跟随系统覆盖前台与后台、CodeMirror、Mermaid 和公式。主题使用 cookie 与 SSR 属性，系统模式由 CSS 媒体查询处理首屏。编辑器切换主题仅重新配置样式，保留文字、选择位置和撤销历史；修复独立编辑页刷新时编辑器未挂载的问题。

v2 备份包含组织结构、站点设置、正文、历史和图片，兼容 v1。ZIP 提供 Markdown、JSON 和原始图片，已用 Python 标准 zipfile 校验 UTF-8 与 CRC。导入采用预览、计划令牌、确认和事务，仅新增内容；恢复设置需显式勾选。旧数据升级保留原始 JSON，默认不覆盖已有内容及账号配置。
