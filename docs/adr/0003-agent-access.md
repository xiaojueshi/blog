# 使用受限凭据和本机 MCP 管理内容

博客正文和版本保存在工作台数据库，本地与线上是独立实例。为了从多个 Agent 操作同一套内容规则，使用仓库维护的 skills 描述写作、组织和发布流程，由本机 MCP 服务提供统一工具，并通过 Magpie Library 分发。

Agent 使用独立于管理员会话的可撤销凭据。凭据默认 90 天有效，只存储摘要；分别授予读取、编辑稿写入、发布和分类管理权限，不允许访问站点设置、备份、知识库或附件管理。线上与本地分别签发凭据，默认分别保存在 macOS 钥匙串；同一实例可以另发凭据给单独的设备或 Agent。

不直接把 Agent 凭据当作管理员会话：现有管理员接口包含设置、备份等超出需要的能力。Agent 专用接口按动作验证权限，复用内容与分类的业务逻辑，保留版本冲突和事务约束。凭据不进入内容备份。

发布、撤回以及影响分类和标签的操作先生成预览，在当前对话得到用户明确确认后执行。预览携带修订信息，过期或内容变化时拒绝执行。对话确认依赖 Agent 遵守 skill；服务端的凭据权限和修订检查提供独立的访问边界。

本机 stdio MCP 服务避免额外暴露 MCP 网络端口，但要求运行 Agent 的机器能够访问服务程序和钥匙串。远程 Agent、跨设备分发和自动同步不属于首版。
