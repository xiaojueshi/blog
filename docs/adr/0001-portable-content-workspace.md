# 构建可迁移的个人内容工作台

采用 Nuxt、Vue 和 TypeScript 自建单管理员内容工作台，公开博客是其对外窗口。正文保存为 Markdown，数据库管理元数据与版本；内容发布独立于代码构建，不采用依赖 Git 提交与构建才能发布的 CMS 工作流。

首选 Cloudflare Workers、D1 和 R2，以降低初期基础设施成本；数据库与附件访问集中封装，保留 Node.js、SQLite 和 S3 兼容存储的迁移目标。该目标必须通过备份恢复与部署验证，不承诺不同提供商之间无修改迁移。

相比直接绑定托管 CMS，自建后台增加开发与维护成本，但使内容模型、私人笔记、发布流程和数据导出由项目掌握。使用开源组件补足编辑与渲染能力，不重新实现 Markdown 解析器。

独立管理员账号，不开放注册；服务端鉴权，不要求端到端加密。私密正文、附件、搜索和缓存都必须执行访问控制。
