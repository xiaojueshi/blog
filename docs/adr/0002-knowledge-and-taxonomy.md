# 通过引用组织知识库，以稳定身份维护内容分类

知识库使用可嵌套的章节目录，节点引用已有内容而不复制正文。公开目录仅呈现已发布内容及其必要祖先章节，标题取公开版本，避免编辑稿和私人笔记经目录泄露。知识库可以归档恢复，归档不删除文章。

类型、分类与标签通过稳定身份关联内容，名称可独立修改；停用类型保留已有内容，分类迁移及标签合并以事务更新关联并保留内容历史。保留三个内置内容行为，避免任意自定义类型字段使个人工作台演变成复杂 CMS。

完整备份采用版本二格式，包含目录、术语和站点设置，兼容版本一。恢复先预览、再校验预览是否过期、最后原子写入；默认仅新增并保留目标站点设置，避免通过恢复包覆盖已有内容或账号配置。
